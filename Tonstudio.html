Tonstudio

Songs aufnehmen und arrangieren – mit USB-MIDI-Keyboard, Bildschirm-Tastatur, Akkordtasten und Mikrofon. Alles bleibt auf diesem Gerät.

Am besten in Chrome (Android) bzw. Chrome, Edge oder Firefox (Laptop). Das zuletzt bearbeitete Projekt wird automatisch wiederhergestellt.

Verzögerung (Latenz)

Messen: Kopfhörer abziehen, Lautsprecher laut stellen, ruhige Umgebung. Das Tonstudio spielt fünf Klicks und misst, wie spät das Mikrofon sie hört. Dieser Wert wird bei Gesangsaufnahmen automatisch abgezogen, damit die Aufnahme genau zur Begleitung passt.

Grundprinzip

  • Ein Song besteht aus Spuren (Instrument, Schlagzeug, Mikrofon). Auf jeder Spur liegen Bereiche (Regionen).
  • Spur antippen = auswählen. Gespielt und aufgenommen wird immer auf der ausgewählten Spur.
  • ● startet die Aufnahme ab der Abspielposition (mit Vorzähler, falls eingeschaltet), ▶/■ beendet sie.
  • Ins Lineal tippen setzt die Abspielposition; im Lineal ziehen legt den Bereich der Schleife fest.

Bereiche bearbeiten

  • Bereich ziehen = verschieben, rechten Rand ziehen = verlängern/kürzen.
  • Doppeltippen auf einen Bereich öffnet den Editor; Doppeltippen auf eine leere Stelle legt einen neuen Bereich an.
  • Über der Registerleiste: Duplizieren, an der Abspielposition teilen, löschen.
  • Alles lässt sich mit ↶ rückgängig machen.

Editor

  • Piano-Roll: leere Stelle antippen = Note setzen, Note ziehen = verschieben, rechten Rand ziehen = Länge, Note doppelt antippen = löschen, auf leerer Fläche wischen = verschieben der Ansicht.
  • Schlagzeug: Raster antippen schaltet Schläge an/aus. Unter „Vorlage“ gibt es fertige Rhythmen.
  • „Quantisieren“ rückt ungenau gespielte Noten auf das Raster.

Gesang aufnehmen

  • Mikrofon-Spur auswählen, Kopfhörer aufsetzen (sonst nimmt das Mikrofon die Begleitung mit auf), ● drücken.
  • Einmalig unter Einstellungen die Latenz messen, damit Gesang und Begleitung zusammenpassen.

Speichern & Weitergeben

  • Das Projekt wird automatisch im Browser gesichert. Zum Weitergeben: ☰ Projekt → „Projekt speichern“ (Datei mit allen Spuren und Aufnahmen).
  • Fertiger Song: „Song exportieren als WAV“. Noten für andere Programme (z. B. MuseScore): „als MIDI“.
